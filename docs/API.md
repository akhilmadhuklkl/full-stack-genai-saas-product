# API overview

The authoritative interactive API contract is generated by FastAPI:

- `/docs` for Swagger UI
- `/redoc` for ReDoc
- `/openapi.json` for machine-readable OpenAPI

All `/api/v1` routes use JSON unless noted otherwise. Protected routes require:

```http
Authorization: Bearer <access_token>
```

Browser clients may use the `HttpOnly` `forge_access_token` cookie set during registration
or login. API clients can continue using the bearer-token header.

## Authentication and account

| Method | Route | Purpose |
|---|---|---|
| POST | `/api/v1/auth/register` | Create an account |
| POST | `/api/v1/auth/login` | Sign in and receive a token |
| POST | `/api/v1/auth/refresh` | Exchange a refresh token for new credentials |
| POST | `/api/v1/auth/logout` | Revoke the current access token |
| GET | `/api/v1/me` | Read the current account |
| POST | `/api/v1/me/password` | Change the current password |
| GET | `/api/v1/me/usage` | Read hourly review usage |

## Projects and files

| Method | Route | Purpose |
|---|---|---|
| GET | `/api/v1/projects` | List owned projects |
| POST | `/api/v1/projects` | Create a project |
| GET | `/api/v1/projects/{project_id}` | Read a project |
| PATCH | `/api/v1/projects/{project_id}` | Rename/configure a project |
| DELETE | `/api/v1/projects/{project_id}` | Delete a project |
| GET | `/api/v1/projects/{project_id}/stats` | Read project statistics |
| POST | `/api/v1/projects/{project_id}/archive` | Import a ZIP archive |
| POST | `/api/v1/projects/{project_id}/files` | Add a file |
| GET | `/api/v1/projects/{project_id}/files` | List files |
| GET | `/api/v1/files/{file_id}` | Read a file |
| PUT | `/api/v1/files/{file_id}` | Replace file content |
| DELETE | `/api/v1/files/{file_id}` | Delete a file |

## Reviews and jobs

| Method | Route | Purpose |
|---|---|---|
| POST | `/api/v1/reviews` | Create a queued review |
| GET | `/api/v1/projects/{project_id}/reviews` | List review history |
| GET | `/api/v1/reviews/{review_id}` | Read findings and summary |
| GET | `/api/v1/reviews/{review_id}/export` | Download JSON or Markdown results |
| GET | `/api/v1/reviews/{review_id}/stream` | Stream review events using SSE |
| POST | `/api/v1/reviews/{review_id}/run` | Run synchronously |
| POST | `/api/v1/reviews/{review_id}/enqueue` | Run asynchronously |
| GET | `/api/v1/jobs/{job_id}` | Read background-job status |
| POST | `/api/v1/reviews/{review_id}/retry` | Retry a failed review |
| POST | `/api/v1/reviews/{review_id}/recover` | Requeue a stale processing review |
| PATCH | `/api/v1/reviews/{review_id}/status` | Update review state |
| POST | `/api/v1/reviews/{review_id}/findings` | Add a structured finding |

## System

| Method | Route | Purpose |
|---|---|---|
| GET | `/health` | Lightweight liveness check |
| GET | `/health/details` | Database, Ollama, Redis, and worker status |
| GET | `/metrics` | Prometheus-compatible operational metrics |

## Filtering

Examples:

```text
GET /api/v1/projects/1/files?search=auth
GET /api/v1/projects/1/reviews?status=completed
GET /api/v1/projects/1/reviews?search=security&page=1&page_size=10
GET /api/v1/reviews/3?severity=high
```
