# Changelog

All notable changes to Forge Review are documented here.

## [Unreleased]

- Review job retries, execution metadata, and failed-review retry controls
- JSON and Markdown review exports
- Review history search, filtering, pagination, and dashboard charts

## [0.1.0] - 2026-11-18

### Added

- Custom browser dashboard
- User registration, login, and password management
- Project and source-file management
- ZIP archive ingestion with path-traversal protection
- Local Ollama code reviews
- Streaming and asynchronous review jobs
- Review findings, history, statistics, and filters
- Project-specific review instructions
- Prompt versioning
- AI evaluation fixtures and comparison reports
- Redis-compatible caching and rate limiting
- Alembic database migrations
- Health checks and structured request logging
- GitHub Actions quality and security checks
